# Real-Time Web Object Detection

> **Domain:** Manufacturing

## Overview

Browser-based detection application enabling operators to identify objects in real-time with instant bounding boxes and audit-ready evidence capture for supervisors.

## Skills & Technologies

- Python
- Flask
- SQLite
- OpenCV
- Object Detection
- HTML5 Camera APIs
